# 0003. Written in Go

## Context

Caduceus is mostly a long-running service that starts and watches agent processes, talks over a local socket, and
glues git, gh, JSON and HTTP together, on an 8 GB box without a C compiler, with code written mostly by delegates.

## Options

- A. Go: one static binary; same language as hermes-relay and its host helpers (4.5 and 13.5 MB of memory today).
- B. TypeScript on Bun: fastest to write, but a second server language.
- C. Python: hermes-dispatch as is, but weak for a long-running service.
- Also weighed: Elixir (best fit for supervision, most costly to adopt), Rust (slow to write, no linker on the box),
  Kotlin (JVM memory), Swift on Linux (thin libraries, Docker-only builds), Deno, Odin (pre-1.0, manual memory, no
  TOML or HTTP in its standard library, little model fluency, builds through LLVM and most likely clang).

## Decision

A, Go (Martin: "lets use go then").

## Consequences

- hermes-dispatch's Python logic is rewritten; its 25 tests are the port's spec.
- Dependencies are added by Hermes, not delegates (`GOPROXY=off` in runs). Race tests run in the golang container.
